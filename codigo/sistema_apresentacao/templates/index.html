Este projeto foi desenvolvido com Python (Flask), HTML/CSS e SQLite. Para executá-lo com todos os recursos de banco de dados, cadastro e login:

Como executar no terminal:
  1. Instale as dependências: pip install -r requirements.txt
  2. Execute o servidor Flask: python app.py
  3. Abra no seu navegador: http://127.0.0.1:5000
